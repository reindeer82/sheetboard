Connect Google Sheets
Enter your OAuth Client ID and the Spreadsheet ID. Data stays in your browser — nothing is sent to any third-party server.
Found in the URL: docs.google.com/spreadsheets/d/ID/edit
1
Go to console.cloud.google.com → create or select a project.
2
APIs & Services → Library → search & enable Google Sheets API.
3
APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID → Web Application.
4
Authorised JavaScript origins — add your WordPress site URL (must be https://). Also add http://localhost for local testing.
5
Copy the Client ID (ends in .apps.googleusercontent.com) and paste it above.
6
On the OAuth Consent Screen, add your own Google account as a Test User while in testing mode.
WordPress Embedding
Three ways to embed SheetBoard on your WordPress site, from easiest to most integrated.
A
Iframe (Easiest)
Host sheetboard.html on any static host (GitHub Pages, Netlify, Cloudflare Pages — all free). Then in WordPress use a Custom HTML block:
<iframe src="https://your-host/sheetboard.html" style="width:100%;height:85vh;border:none" allow="identity-credentials-get"></iframe>
B
Custom Page Template
Copy sheetboard.html into your theme folder as page-sheetboard.php, adding <?php get_header(); ?> and <?php get_footer(); ?>. In WordPress, create a new Page and select the SheetBoard template.
C
Full-Width Block (No coding)
Create a new Page, set the template to Full Width or No Header/Footer. Add a Custom HTML block and paste the entire contents of sheetboard.html inside it. Works out of the box with most themes.
!
Important: Google OAuth requires your WordPress site to run on https://. Make sure your domain has an SSL certificate (free via Let's Encrypt on most hosts).
